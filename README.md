# Wiz AIネックレス — ハードウェア要件サイト

首から下げるAIデバイス（AIネックレス）の **ハードウェア要件** を、図つきでわかりやすくまとめた静的サイトです。各セクションで **ver3（現行）** と **理想** をタブで切り替えて比較できます。

🔗 **公開URL: https://device-arc.vercel.app**

## 内容

- **部品配置（立体図）** — マイク・カメラ・スピーカー・ボタン等の配置を SVG の立体図で表示。右上のタブで **ver3 / 理想** を切替
  - **ver3**：マイク（上端＋下端）・カメラ（中央）・LED・側面PTTボタンの基本構成
  - **理想**：前面 全面ディスプレイ／カメラ（前面左上）／下マイク×2／スピーカー／側面ボタン×3（yes・no・talk）。さらに **ネックレス型ストラップ（電源サブ＝バッテリー内蔵）** と、その頂部ジョイントから伸びる **有線イヤホン（ストラップにマグネットで着脱・充電し一体化）** を図示
- **要件一覧** — 仕様表。こちらも **ver3 / 理想** をタブで切替
- **システム構成** — ネックレス → BLE → スマホ → OpenAI Realtime
- **他社比較** — DJI Mic / AnkerWork / PLAUD のマイク構成比較
- **検討事項** — 未決事項（音声の送り先・圧縮方式・電池もち・カメラ仕様 など）

## 仕様サマリ

### ver3（現行）
| 項目 | 値 |
|---|---|
| 寸法 | 40 × 30 × 10 mm（縦長・胸装着） |
| MCU | ESP32-S3（BLE 5.0 / 2M PHY） |
| マイク | デジタルMEMS ×2（上端＋下端・間隔 ≈ 40mm） |
| カメラ | ×1（中央・前方） |
| スピーカー | なし（スマホ再生にフォールバック） |
| 電源 | LiPo 640mAh |
| 入力 | 側面PTTボタン |

### 理想（スマホ相当のスタンドアロン機）
| 項目 | 値 |
|---|---|
| SoC | Qualcomm Snapdragon 系（オンデバイスAI／ローカルLLM推論） |
| OS | Android ベース（スマホ不要） |
| ディスプレイ | 前面 全面タッチディスプレイ |
| マイク | MEMS ×3（上面 ×1＝自分／下面 左右 ×2＝相手） |
| スピーカー | 前面下中央 ×1 |
| イヤホン | 有線 ×2・ストラップにマグネット着脱／充電（未使用時は一体化） |
| 電源 | 本体 LiPo 640mAh ＋ ストラップ内蔵バッテリー（電源サブ） |
| 接続 | 5G ／ Wi-Fi 6 ／ Starlink（衛星）＋ BLE 5.x |
| 入力 | タッチ＋側面ボタン ×3（yes / no / talk） |

## 開発

ビルド不要の静的サイト（`index.html` + `styles.css`）。

```bash
# ローカル確認
open index.html

# Vercel デプロイ
vercel deploy --prod
```
